## 概述

电脑开久了,后台会跑着大量程序:聊天软件、更新助手、用完没关的程序,甚至还有银行网站要求安装的安全程序。一个个找出来关闭非常麻烦。

KCleaner 只需在 **主页** 点击一次 **清理**,就会只保留 Windows 运行所必需的程序,关闭其余全部程序,然后再释放一次剩余内存。显卡 · 声卡等必要驱动和可信的杀毒软件不会被关闭;而冒用 Windows 系统程序名称的伪装程序会被关闭。程序只是被关闭,不会被删除。

此外,还以标签页的形式附带了三个清理工具:

- **启动** — 将开机时自动启动的程序 · 计划任务 · 服务禁用而不删除。
- **清理** — 挑选并删除已安装应用留下的缓存 · 临时文件等残留。
- **捆绑** — 找出并卸载银行 · 政府机关网站要求安装的安全程序。

## 主要功能

- **一键关闭** — 只保留必要程序,用一个按钮关闭其余所有程序。
- **安全的判断标准** — 保留 Windows 必要程序、显卡 · 声卡驱动和可信的杀毒软件;只模仿系统程序名称的伪装程序会被关闭。
- **内存清理** — 关闭完成后,再释放一次剩余内存。
- **例外列表** — 需要一直运行的程序可以自行指定,不被关闭。
- **清理结果** — 清理结束后会打开结果页面,显示已关闭的程序和内存变化。
- **自动启动管理** — 在一个列表中启用或禁用分散在启动文件夹 · 注册表 · 计划任务 · 服务中的自动启动项。
- **残留文件清理** — 只针对本机已安装的应用,分析并删除缓存 · 临时文件 · 日志。书签 · 密码 · 浏览记录等个人记录默认不勾选。
- **卸载强制安装的程序** — 找出银行 · 政府机关的安全程序并列出,一个按钮即可运行其卸载程序。
- **托盘图标** — 安装版在登录后以图标形式待在通知区域,点击即可打开。
- **深色模式** — 界面颜色随 Windows 应用模式(浅色 · 深色)变化。
- **9 种语言** — 韩语 · 英语 · 日语 · 中文 · 俄语 · 意大利语 · 法语 · 西班牙语 · 阿拉伯语。

## 使用方法

### 快速上手

1. 如果有打开的文档或未完成的工作,请先保存。包括浏览器和聊天软件在内,所有非必要程序都会被关闭。
2. 运行 KCleaner,在管理员权限确认窗口中点击 **是**。
3. 在 **主页** 上点击 **清理** 按钮。
4. 按钮位置会出现旋转的进度标识,在此期间会关闭不必要的程序并清理内存。
5. 完成后,浏览器中会打开清理结果页面,KCleaner 窗口会自动关闭。

### 这种情况怎么办

**电脑变慢时一次性清理**
在 **主页** 上点击 **清理** 按钮即可。后台运行的程序会被一并关闭,内存也会被释放。程序只是被关闭而不会被删除,需要的程序重新运行后照常使用即可。

**点击清理前要注意的事**
浏览器、聊天软件、文档编辑器等非必要程序即使正在打开也会被关闭。如有未保存的工作,请先保存。Windows 资源管理器和桌面、显卡 · 声卡驱动、可信的杀毒软件会继续运行。

**有需要一直运行的程序时(例外列表)**
如果是安装版,右键点击通知区域中的 KCleaner 图标 → **例外列表**。记事本打开后,每行写一个不希望被关闭的程序,然后保存。

- `程序.exe*` — 可执行文件名完全相同的程序(例: `editplus.exe*`)
- 不带 `*` — 路径中包含该文字的所有程序(例: `\EditPlus\` 表示该文件夹中的所有程序)

从下一次点击 **清理** 按钮开始,列出的程序将不会被关闭。免安装版可在 `KCleaner.exe` 旁边创建 `NoClean.txt`,按同样方式填写。

**查看清理结果**
清理结束后,浏览器中会打开结果页面,显示已关闭的程序和清理前后的内存。KCleaner 窗口在完成工作后会自动关闭。

**通过托盘图标直接运行**
安装版在登录后稍等片刻,KCleaner 图标就会出现在通知区域。左键点击图标即可打开 KCleaner;如果已经打开,该窗口会被调到前面。右键菜单中有 **KCleaner** · **例外列表** · **关于** · **退出**。点击 **退出** 后,图标会消失,直到下次登录。

**关闭开机自动启动的程序**
在 **启动** 标签页中点击该程序,然后点击 **禁用**。这不是删除项目而是将其禁用,只是从下次开机起不再自动启动,程序本身仍可照常使用。该行会以灰色留在原位,也可以马上用 **启用** 恢复。

**想重新启用已禁用的项目时**
在 **启动** 标签页中勾选 **所有程序**,之前禁用的项目会以灰色行一并显示。点击该行再点击 **启用**,从下次开机起就会再次运行。

**关闭更新计划任务和服务**
**位置** 为 **计划任务** 的行是在设定时间自动运行的任务;**服务** 是 Windows 启动时运行的后台服务。点击 **禁用** 后,计划任务到了设定时间也不会运行,服务在开机时或被其他程序调用时都不会启动。建议先确认服务属于哪个程序再禁用。

**不知道某个启动项是什么时**
双击该行,浏览器会打开并显示该项目的相关信息。

**已卸载程序的自动启动项还残留时**
先将该行切换为 **禁用**,然后右键 → **删除**,在确认窗口中点击 **是**。已删除的项目无法恢复,请只删除确定不需要的项目。删除服务后会显示"正在运行的服务将在重启后被完全移除"的提示,重启一次电脑即可彻底清除。

**把自动启动列表保存为文件**
在 **启动** 标签页中右键 → **保存列表**,会将包括列表中未显示的 Windows 基本项目在内的全部自动启动项保存为文本文件。为防止误关,Windows 必需的服务和任务从一开始就在列表中隐藏,即使勾选 **所有程序** 也不会显示。

**清理残留文件,找回磁盘空间**
第一次打开 **清理** 标签页时,会查找本机已安装的应用并显示 **已安装应用 N 个**,并按分类只列出这些应用的清理项目。保持默认勾选,点击 **分析** 即可看到要删除的文件和大小;点击 **清理** 按钮则删除已分析的内容。**分析** 不会删除任何东西,也可以只用它先看看能释放多少空间。

**自行选择要删除的项目**
点击分类行可展开并显示项目,点击项目行可切换勾选。分类行的复选框可一次勾选或取消整个分类,只勾选了部分项目时会显示为灰色。更改过的勾选会被记住,下次打开时照样使用。要恢复初始状态,请在列表中右键 → **恢复默认**。

**也想删除浏览记录或最近文件列表时**
书签 · 收藏夹 · 密码 · 网页浏览记录 · 聊天记录等用户留下的记录,为防止误删默认不勾选。对于缓存和最近文件列表混在一起的应用,另外设有 **… · 使用记录** 项目。如果也想删除这些记录,请手动勾选该项目。

**清理按钮无法点击时**
只有已勾选的项目全部经过 **分析** 且有可删除的内容时,**清理** 按钮才会启用。如果分析后又勾选了新项目,或刚完成清理,请再点击一次 **分析**。

**带感叹号的项目**
这是删除前有需要了解之处的项目。鼠标悬停可查看说明(英文);如果勾选了这类项目,点击 **清理** 按钮时会再确认一次。

**浏览器处于打开状态时**
正在使用的文件不会被处理,会直接跳过。想清除更多浏览器缓存,请关闭浏览器后再清理,或先在 **主页** 上点击 **清理** 按钮后再进行清理。

**我的文件安全吗**
文档 · 桌面 · 图片 · 视频 · 音乐 · 下载文件夹以及隐藏 · 系统文件既不分析也不清理。联网时,清理列表会自动更新为经过审核的最新版本。

**删除银行网站安装的安全程序**
打开 **捆绑** 标签页,只会显示本机已安装的键盘安全 · 数字证书 · 防火墙等银行 · 政府机关安全程序。选择要删除的程序后点击 **卸载** 或双击该行,就会像控制面板的"卸载程序"一样打开该程序的卸载程序。卸载完成后会自动从列表中消失。没有可删除的程序时会显示 **没有需要卸载的程序**。需要时可以随时从网站重新安装。

**用键盘浏览列表**
在 **启动** 和 **捆绑** 标签页中,可用 **↑** · **↓** 移动选择行,**F5** 重新加载列表。名称过长被截断时,可以拖动列标题之间的边界调整列宽。

**已经在运行时再次运行**
KCleaner 只能运行一个。窗口已打开时再次运行不会启动新的实例,而是将已打开的窗口调到前面。

## 设置

没有需要设置的内容。不希望被关闭的程序用上面的 **例外列表** 指定,清理 标签页的勾选在界面上更改后会自动记住。以下各项由 KCleaner 自动跟随:

| 项目 | 跟随 |
|---|---|
| 语言 | Windows 区域设置(不支持的语言显示为英语) |
| 界面颜色 | Windows 应用模式(浅色 · 深色)— KCleaner 运行期间更改也会立即生效 |

## 系统要求

- Windows 10 · Windows 11(64 位)
- 管理员权限 — 关闭程序和更改自动启动项时需要。运行时会弹出确认窗口。
- 无需另外安装任何组件。
- 网络连接用于新版本提示、列表更新和清理结果页面。即使没有网络,也能用内置列表照常清理。
