## 概要

パソコンを長くつけっぱなしにしていると、メッセンジャー、アップデート補助ツール、使ったまま閉じていないプログラム、銀行サイトが入れたセキュリティ プログラムまで、たくさんのプログラムが裏で動いています。1 つずつ探して終了するのは手間がかかります。

KCleaner は **ホーム** の **クリーン** を 1 回押すだけで、Windows の動作に欠かせないプログラムだけを残して残りをすべて終了し、そのあと空いたメモリをもう一度解放します。グラフィック · サウンドなどの必須ドライバーと信頼できるウイルス対策ソフトは終了せず、Windows 標準プログラムと同じ名前を装ったプログラムは終了します。プログラムは終了するだけで、削除はしません。

さらに、3 つの整理ツールがタブとして入っています。

- **起動** — Windows の起動時に自動で立ち上がるプログラム · タスク · サービスを、削除せずに無効化します。
- **クリーンアップ** — インストール済みアプリが残したキャッシュ · 一時ファイルなどの不要ファイルを選んで削除します。
- **バンドル** — 銀行 · 公的機関のサイトがインストールを求めたセキュリティ プログラムを見つけて削除します。

## 主な機能

- **まとめて終了** — 必須プログラムだけを残し、残りのプログラムをボタン 1 つで終了します。
- **安全な基準** — Windows の必須プログラム、グラフィック · サウンド ドライバー、信頼できるウイルス対策ソフトは残します。名前だけをまねた偽のシステム プログラムは終了します。
- **メモリの整理** — 終了が済むと、空いたメモリをもう一度解放します。
- **除外リスト** — 常に動かしておく必要があるプログラムは、自分で指定して終了の対象から外せます。
- **整理結果** — 整理が終わると、終了したプログラムとメモリの変化を示す結果ページが開きます。
- **自動実行の管理** — スタートアップ · レジストリ · タスク · サービスに散らばった自動実行項目を、1 つのリストで有効 · 無効にします。
- **不要ファイルの整理** — このパソコンにインストールされているアプリだけを対象に、キャッシュ · 一時ファイル · ログを分析して削除します。ブックマーク · パスワード · 閲覧履歴などの個人の記録は、既定ではチェックしません。
- **強制インストール プログラムの削除** — 銀行 · 公的機関のセキュリティ プログラムを見つけて一覧にし、ボタン 1 つでアンインストーラーを実行します。
- **トレイ アイコン** — インストーラー版はサインインすると通知領域にアイコンとして待機し、クリックするとすぐに開きます。
- **ダーク モード** — Windows のアプリ モード(ライト · ダーク)に合わせて画面の色が変わります。
- **9 言語** — 韓国語 · 英語 · 日本語 · 中国語 · ロシア語 · イタリア語 · フランス語 · スペイン語 · アラビア語。

プログラムの終了と自動実行項目の変更には管理者権限が必要なため、実行時に Windows が管理者権限の確認画面を表示します。**はい** を押してください。

## 使い方

### はじめての使い方

1. 開いている文書や作業中のものがあれば、先に保存します。ブラウザーやメッセンジャーを含め、必須でないプログラムはすべて終了します。
2. KCleaner を実行し、管理者権限の確認画面で **はい** を押します。
3. **ホーム** で **クリーン** を押します。
4. ボタンの位置で進行表示が回り、その間に不要なプログラムを終了してメモリを整理します。
5. 終わるとブラウザーに整理結果のページが開き、KCleaner のウィンドウは自動で閉じます。

### 画面構成

|---|---|
| **ホーム** | **クリーン** ボタンがある最初の画面 |
| **起動** | 起動時に立ち上がる項目を有効 · 無効にする画面 |
| **クリーンアップ** | インストール済みアプリの不要ファイルを分析して削除する画面 |
| **バンドル** | 銀行 · 公的機関のセキュリティ プログラムを削除する画面 |
| KILHO.net ロゴ | KCleaner の紹介ページを開きます |

各タブは最初に押したときにリストを読み込みます。**ホーム** の **クリーン** だけを使うなら、ほかのタブを開く必要はありません。

|---|---|

| **全プログラム** | チェックすると、無効にした項目も含めてすべて表示します |
| **無効化** / **有効化** | 選んだ項目を無効または有効にします |

**クリーンアップ**

| 要素 | 役割 |
|---|---|
| 分類の行 | **Windows** · ブラウザー名 · **インターネット** · **マルチメディア** · **ユーティリティ** · **アプリケーション** · **ゲーム** · **その他**。クリックで開閉します |
| 項目の行 | 削除できる不要ファイルの種類 1 つ。チェックしたものだけを分析 · 整理します |

| 要素 | 役割 |
|---|---|
| **プログラム** 列 | このパソコンにインストールされている銀行 · 公的機関のセキュリティ プログラム |

| **削除** | 選んだプログラムのアンインストーラーを実行します |

### こんなときは

**パソコンが重くなったときにまとめて整理する**
**ホーム** で **クリーン** を押すだけです。裏で動いていたプログラムがまとめて終了し、メモリが解放されます。プログラムは終了するだけで削除されないので、必要なプログラムはもう一度起動すればそのまま使えます。

**クリーンの前に確認すること**
ブラウザー、メッセンジャー、文書エディターなど必須でないプログラムは、開いていても終了します。保存していない作業があれば先に保存してください。Windows のエクスプローラーとデスクトップ、グラフィック · サウンド ドライバー、信頼できるウイルス対策ソフトはそのまま残ります。

**常に動かしておきたいプログラムがある(除外リスト)**
インストーラー版なら、通知領域の KCleaner アイコンを右クリック → **除外リスト** を押します。メモ帳が開いたら、終了させたくないプログラムを 1 行に 1 つずつ書いて保存します。

- `プログラム.exe*` — 実行ファイル名が完全に一致するプログラム(例: `editplus.exe*`)
- `*` を付けないと — その文字がパスに含まれるすべてのプログラム(例: `\EditPlus\` はそのフォルダーのプログラムすべて)

次に **クリーン** を押したときから、書いたプログラムは終了しません。ポータブル版は `KCleaner.exe` の隣に `NoClean.txt` を作り、同じように書きます。

**整理結果を確認する**
整理が終わるとブラウザーに結果ページが開き、終了したプログラムと整理前後のメモリを表示します。KCleaner のウィンドウは作業を終えると自動で閉じます。

**トレイ アイコンからすぐに実行する**
インストーラー版は、サインインしてしばらくすると通知領域に KCleaner のアイコンが表示されます。アイコンを左クリックすると KCleaner が開き、すでに開いていればそのウィンドウが前面に出ます。右クリック メニューには **KCleaner** · **除外リスト** · **このソフトについて** · **終了** があります。**終了** を押すと、アイコンは次のサインインまで消えます。

**起動時に自動で立ち上がるプログラムを止める**
**起動** タブでそのプログラムをクリックし、**無効化** を押します。項目を削除するのではなく無効にするだけなので、次回の起動から立ち上がらなくなるだけで、プログラムはそのまま使えます。その行は薄い表示のまま残るので、すぐに **有効化** で戻すこともできます。

**無効にした項目を再び有効にしたい**
**起動** タブで **全プログラム** をチェックすると、以前に無効にした項目が薄い行で一緒に表示されます。その行をクリックして **有効化** を押すと、次回の起動から再び実行されます。

**アップデートのタスクやサービスを止める**
**場所** が **タスク** の行は決まったタイミングで自動実行されるタスクで、**サービス** は Windows の起動時に立ち上がるバックグラウンド サービスです。**無効化** を押すと、タスクは決まった時刻になっても実行されず、サービスは起動時にもほかのプログラムから呼び出されても起動しません。サービスは、どのプログラムが使っているものか確認してから無効にするのがおすすめです。

**起動の項目が何なのかわからない**
その行をダブルクリックすると、ブラウザーが開いてその項目に関する情報を表示します。

**アンインストールしたプログラムの自動実行項目が残っている**
まずその行を **無効化** にしてから、右クリック → **削除** を押し、確認画面で **はい** を押します。削除した項目は元に戻せないので、確実に不要なものだけを削除してください。サービスを削除すると「実行中だったサービスは再起動後に完全に削除されます」という案内が表示されますが、パソコンを一度再起動すればきれいに片付きます。

**自動実行のリストをファイルに残す**
**起動** タブで右クリック → **リストを保存** を押すと、リストに表示されない Windows の基本項目も含め、すべての自動実行項目がテキスト ファイルに保存されます。Windows に欠かせないサービスやタスクは誤って無効にしないよう最初からリストに表示せず、**全プログラム** をチェックしても表示されません。

**不要ファイルを消してディスクの空きを取り戻す**
**クリーンアップ** タブを初めて開くと、このパソコンにインストールされているアプリを探して **インストール済みアプリ N 個** と表示し、それらのアプリの整理項目だけを分類ごとに表示します。既定のチェックのまま **分析** を押すと削除するファイルとサイズが表示され、**クリーン** を押すと分析したものを削除します。**分析** は何も削除しないので、どれだけ空けられるかを先に確かめるだけでもかまいません。

**削除する項目を自分で選ぶ**
分類の行をクリックすると開いて項目が表示され、項目の行をクリックするとチェックが切り替わります。分類の行のチェック ボックスはその分類全体を一度にチェック · 解除し、一部だけチェックされているときは灰色で表示されます。変更したチェックは記憶され、次に開いたときもそのまま使われます。最初の状態に戻すには、リストで右クリック → **既定に戻す** を押します。

**閲覧履歴や最近使ったファイルの一覧も消したい**
ブックマーク · お気に入り · パスワード · Web の閲覧履歴 · 会話の履歴など、ユーザーが残した記録は誤って消さないよう、既定ではチェックしません。キャッシュと最近使ったファイルの一覧が混ざっているアプリには、**… · 使用履歴** という項目を別に用意しています。記録まで消したい場合は、その項目を自分でチェックしてください。

**クリーンが押せない**
**クリーン** は、チェックした項目をすべて **分析** し、削除するものがあるときだけ有効になります。分析のあとで新しくチェックしたときや、整理を終えたばかりのときは、もう一度 **分析** を押してください。

**感嘆符が付いた項目**
削除の前に知っておくべき点がある項目です。マウスを重ねると説明(英語)が表示され、このような項目がチェックされていると、**クリーン** を押したときにもう一度確認します。

**ブラウザーが開いている**
使用中のファイルには手を付けずにスキップします。ブラウザーのキャッシュをもっと消すには、ブラウザーを閉じてから整理するか、先に **ホーム** の **クリーン** を押してから整理してください。

**自分のファイルは安全?**
ドキュメント · デスクトップ · ピクチャ · ビデオ · ミュージック · ダウンロードの各フォルダーと、隠しファイル · システム ファイルは、分析も整理もしません。整理のリストは、インターネットに接続されていれば確認済みの最新版に自動で切り替わります。

**銀行サイトが入れたセキュリティ プログラムを削除する**
**バンドル** タブを開くと、このパソコンにインストールされているキーボード セキュリティ · 電子証明書 · ファイアウォールなど、銀行 · 公的機関のセキュリティ プログラムだけを表示します。削除するプログラムを選んで **削除** を押すか、その行をダブルクリックすると、コントロール パネルの「プログラムのアンインストール」と同じ方法で、そのプログラムのアンインストーラーが開きます。削除が終わるとリストから自動で消えます。削除するものがなければ **削除するプログラムはありません** と表示されます。必要になったらサイトから再インストールできます。

**キーボードでリストを見る**
**起動** と **バンドル** タブでは、**↑** · **↓** で行を移動しながら選べ、**F5** でリストを読み込み直します。名前が長くて切れて見えるときは、列見出しの境界をドラッグして列幅を調整できます。

**すでに実行中なのにもう一度実行した**
KCleaner は 1 つしか実行されません。ウィンドウが開いている状態でもう一度実行しても新しく起動せず、すでに開いているウィンドウが前面に出てきます。

## 設定

設定する項目はありません。終了させたくないプログラムは上の **除外リスト** で、クリーンアップのチェックは画面で変えると自動で記憶されます。KCleaner は次のものに自動で従います。

| 項目 | 従うもの |
|---|---|
| 言語 | Windows の地域設定(対応していない言語の場合は英語) |
| 画面の色 | Windows のアプリ モード(ライト · ダーク)— KCleaner を開いている間に変更しても、すぐに反映されます |

## 動作環境

- Windows 10 · Windows 11(64 ビット)
- 管理者権限 — プログラムの終了と自動実行項目の変更に必要です。実行時に確認画面が表示されます。
- 別途インストールが必要なコンポーネントはありません。
- インターネット接続は、新バージョンのお知らせ、リストの更新、整理結果のページに使います。接続がなくても、内蔵のリストで整理はそのまま行えます。

## アップデート

KCleaner は自動でアップデート **しません**。起動時に新しいバージョンがあるかを確認してお知らせを表示し、**[はい]** を押すとダウンロード ページを開いてプログラムを終了します。新しいバージョンは社内での検証を経て手動で配布され、[KCleaner のページ](https://kilho.net/kcleaner)でお知らせします。[アップデート ポリシーのお知らせ](https://en.kilho.net/archives/notice/2940)もご覧ください。
